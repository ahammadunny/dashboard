# Admin Dashboard

A responsive Admin Dashboard layout built as part of **The Odin Project** Intermediate HTML and CSS curriculum.

🔗 **Live Demo:** [View Admin Dashboard](https://github.io)

## Features
* **Two-Dimensional Layout:** Built primarily using CSS Grid for the main dashboard structure, sidebar navigation, header, and content cards.
* **Component Alignment:** Combined CSS Flexbox with Grid to align icons, search bars, user profile details, and action buttons.
* **Custom Styling & Visual Effects:** Styled project cards with accent borders, subtle drop shadows, and custom hover interactions.

## Built With
* Semantic HTML5
* CSS3 (CSS Grid & Flexbox)
* SVG Icons

## What I Learned
* Structuring complex multi-column and multi-row page layouts with nested CSS Grids.
* Controlling spacing, alignment, and proportions across different dashboard sections.
* Managing a Git workflow in WSL and deploying a static site live via GitHub Pages.
* Pair-programming with an AI assistant to debug environment issues, refine visual polish, and deepen my understanding of CSS layout mechanics.
